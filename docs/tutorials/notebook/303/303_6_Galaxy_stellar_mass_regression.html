1. Introduction¶

The two previous notebooks in this series classify and cluster DP2 galaxies by morphology. This notebook explores a different application: estimating a galaxy's stellar mass, a continuous physical quantity, from its photometry, structure, and redshift. Unlike classification (a discrete label) or clustering (an unsupervised grouping), this is a regression problem, the third major category of machine learning methods. The model used throughout this notebook is a RandomForestRegressor.

Estimating stellar mass generally requires fitting a galaxy's full spectral energy distribution (SED) against stellar population synthesis models, which is the approach used to derive the COSMOS2020 stellar masses used as ground truth here. These estimates serve as training labels for a machine-learning model that predicts stellar mass from the observables available in DP2, including photometry, structural properties, and photometric redshift. The aim is to learn the relationship between these observables and stellar mass, making it possible to estimate stellar masses for galaxies beyond the COSMOS2020 sample for which no reference mass is available.

Unlike the previous two notebooks, the redshift used here comes from DP2's own object_photoz catalog rather than a cross-match to COSMOS2020. DP2 provides photometric redshifts for every object from six different estimators (BPZ, DNF, FlexZBoost, GPz, kNN, TPZ) through a catalog accessed separately from the Object table (see the 310-series tutorials on photometric redshifts for a dedicated introduction). These estimates are noisier than COSMOS2020's own deep, many-band SED-fit redshifts, but they are the only redshift available for the vast majority of the field.

In [3]:
VIZIER_MIRRORS = [
    "vizier.cds.unistra.fr", "vizier.cfa.harvard.edu",
    "vizier.china-vo.org", "vizier.idia.ac.za", "vizier.nao.ac.jp",
]


def query_vizier(columns, catalog, *region_args, **region_kwargs):
    """Query VizieR, trying each known mirror in turn."""
    errors = []
    for server in VIZIER_MIRRORS:
        survey = Vizier(columns=columns, catalog=catalog, row_limit=-1, vizier_server=server)
        try:
            return survey.query_region(*region_args, catalog=catalog, **region_kwargs)[0]
        except Exception as error:
            errors.append(f"{server}: {error}")
    details = " | ".join(errors)
    raise RuntimeError(
        "Could not reach VizieR on any known mirror. This may be a wider CDS "
        f"outage, so try again later. Details: {details}") from None

2. Query for galaxy photometry and structure in the COSMOS field¶

Query the Object table in the same 0.8 degree radius around the COSMOS field centre, and with the same clean-sample cuts, used by the previous two notebooks: refExtendedness = 1 to exclude point sources, a signal-to-noise cut in each of g, r, and i, and the same Sersic-fit-quality flags. Include objectId, needed to join against the photometric redshift catalog in the next section.

In [4]:
query = '''SELECT objectId, coord_ra, coord_dec, sersic_index, sersic_reff_major,
       sersic_reff_minor, g_cModelMag, r_cModelMag, i_cModelMag,
       g_cModelMag - r_cModelMag AS g_minus_r, r_cModelMag - i_cModelMag AS r_minus_i
FROM dp2.Object
WHERE CONTAINS(POINT('ICRS', coord_ra, coord_dec), CIRCLE('ICRS', {}, {}, {}))=1
  AND refExtendedness = 1
  AND g_cModel_flag = 0
  AND r_cModel_flag = 0
  AND i_cModel_flag = 0
  AND g_cModelFlux/g_cModelFluxErr > 10
  AND r_cModelFlux/r_cModelFluxErr > 10
  AND i_cModelFlux/i_cModelFluxErr > 10
  AND i_cModelMag < 23
  AND sersic_unknown_flag = 0
  AND sersic_no_data_flag = 0
'''.format(field_centre.ra.deg, field_centre.dec.deg, field_radius)

job = tap_service.submit_job(query)
job.run()
job.wait(phases=["COMPLETED", "ERROR"])
assert job.phase == "COMPLETED"
dp2_tab = job.fetch_result().to_table()
job.delete()

print(f"Retrieved {len(dp2_tab)} DP2 objects")

3. Join against DP2's own photometric redshift catalog¶

DP2's photometric redshifts are found in a separate, LSDB-formatted catalog, object_photoz, not in the Object table itself. Open it with lsdb, restrict it to the same field with a cone search, and join it to the Object query above on objectId. Use the FlexZBoost estimator's point estimate, fzboost_z_best -- one of six estimators available, and the one RTN-124 identifies as the most performant for DP2; see the 310-series tutorials for the full list and how to compare them.

4. Cross-match against COSMOS2020 for stellar mass ground truth¶

DP2 has no stellar mass product of its own, so cross-match against the COSMOS2020 catalog (Weaver et al. 2022, VizieR catalog J/ApJS/258/11) for loglpMassmed, the median stellar mass in log solar mass from a full LePhare SED fit. Keep only objects with FlagCOMBINED = 0 and a reasonably narrow stellar mass confidence interval (B_loglpMassmed - b_loglpMassmed < 0.5 dex). This cross-match is for the training labels only: the redshift used throughout this notebook is still DP2's own FlexZBoost estimate from Section 3, not COSMOS2020's.

Warning: This VizieR query can take a few minutes to run.

In [7]:
cosmos2020_cat = query_vizier(
    ["RAJ2000", "DEJ2000", "loglpMassmed", "b_loglpMassmed", "B_loglpMassmed", "FlagCOMBINED"],
    "J/ApJS/258/11/classic", field_centre, radius=field_radius * u.deg)
assert len(cosmos2020_cat) > 0, "COSMOS2020 VizieR query returned no rows"

coord_cosmos2020 = SkyCoord(
    ra=np.array(cosmos2020_cat["RAJ2000"]), dec=np.array(cosmos2020_cat["DEJ2000"]), unit="deg")
coord_dpz = SkyCoord(ra=dpz["coord_ra"].values, dec=dpz["coord_dec"].values, unit="deg")

idx_cosmos2020, separation, _ = coord_dpz.match_to_catalog_sky(coord_cosmos2020)
is_matched = np.array(separation < 1.0 * u.arcsec)

dpz["logmass"] = np.nan
dpz["mass_lo"] = np.nan
dpz["mass_hi"] = np.nan
dpz["quality_flag"] = -1
dpz.loc[is_matched, "logmass"] = np.array(
    cosmos2020_cat["loglpMassmed"])[idx_cosmos2020[is_matched]]
dpz.loc[is_matched, "mass_lo"] = np.array(
    cosmos2020_cat["b_loglpMassmed"])[idx_cosmos2020[is_matched]]
dpz.loc[is_matched, "mass_hi"] = np.array(
    cosmos2020_cat["B_loglpMassmed"])[idx_cosmos2020[is_matched]]
dpz.loc[is_matched, "quality_flag"] = np.array(
    cosmos2020_cat["FlagCOMBINED"])[idx_cosmos2020[is_matched]]

mass_confidence_interval = dpz["mass_hi"] - dpz["mass_lo"]
dpz["has_ground_truth"] = (
    (dpz["quality_flag"] == 0) & dpz["logmass"].notna()
    & (mass_confidence_interval < 0.5) & (dpz["logmass"] > 6))

print(f"DP2 galaxies with a good-quality stellar mass label: {dpz['has_ground_truth'].sum()}")
print(f"DP2 galaxies with no stellar mass label: {(~dpz['has_ground_truth']).sum()}")

5. Convert to physical units and build features¶

Convert the Sersic effective radius and apparent magnitude to physical units (kpc, absolute magnitude) using the FlexZBoost redshift, following the same approach as 303.4 and 303.5. Build the same ellipticity measure used there too. Do this for every galaxy, not just the labeled ones.

Warning: As in 303.4 and 303.5, sersic_reff_major/sersic_reff_minor in the Object table are too small by a factor of $2\ln(2) \approx 1.386$; the cell below corrects for this before computing reff_kpc (see the DP2 known issues documentation).

In [8]:
sersic_reff_correction = 2 * np.log(2)
dpz["sersic_reff_major"] = dpz["sersic_reff_major"] * sersic_reff_correction
dpz["sersic_reff_minor"] = dpz["sersic_reff_minor"] * sersic_reff_correction

kpc_per_arcsec = cosmo.kpc_proper_per_arcmin(dpz["zphot"].values).to(u.kpc / u.arcsec).value
dpz["reff_kpc"] = dpz["sersic_reff_major"] * kpc_per_arcsec

distance_modulus = cosmo.distmod(dpz["zphot"].values).value
dpz["abs_mag_i"] = dpz["i_cModelMag"] - distance_modulus

reff_major = dpz["sersic_reff_major"]
reff_minor = dpz["sersic_reff_minor"]
dpz["ellipticity"] = (reff_major - reff_minor) / (reff_major + reff_minor)

base_cols = ["g_minus_r", "r_minus_i", "abs_mag_i", "zphot"]
structural_cols = ["sersic_index", "reff_kpc", "ellipticity"]

dpz = dpz.replace([np.inf, -np.inf], np.nan)
labeled = dpz[dpz["has_ground_truth"]].dropna(
    subset=base_cols + structural_cols + ["logmass"]).reset_index(drop=True)

print(f"Labeled galaxies available for training and testing: {len(labeled)}")

Labeled galaxies available for training and testing: 40325

Summary¶

This notebook trains a random forest regressor to estimate galaxy stellar mass from DP2 photometry, color, and structural measurements, using COSMOS2020 SED-fit stellar masses as ground truth and DP2's own FlexZBoost photometric redshift throughout, including for the full-field application. Adding structural measurements to color, magnitude, and redshift gives a modest but real reduction in RMSE, and the model's predicted stellar mass distribution for the full, unlabeled field is consistent with the distribution of the labeled training sample.
